# Test data

- **`recorded/cube.gcode`** is what the real OrcaSlicer wrote for `tests/fixtures.py`'s cube (STL sha256 `bd3eda612de075a1e177e7dbe8e97941c8393df936ccab0087cf24b910fa027a`), sliced once on the Mac on 2026-10-24 with the Elegoo Centauri Carbon 0.4 nozzle machine profile, `0.20mm Standard @Elegoo CC 0.4 nozzle` and `Elegoo PLA @ECC`. `tests/fakes.py`'s `RecordedSlicer` replays it through the real header parser, so CI slices without Orca. It holds no path or address (`scripts/check_addresses.py` reads it).
- **`recorded/cube_pei.gcode`** is the same cube sliced the same way with the plate set to `Textured PEI Plate` (`print_shop.slicer.orca.with_bed_type`), on 2026-10-24: the bed is heated to 45 °C, where the Cool Plate slice above heats it to 35 °C. It differs from `cube.gcode` only in the plate, its temperatures and the timestamp. `RecordedSlicer` picks it when the process profile names that plate.
- **`recorded/presets/cube-<nozzle>-<material>.gcode`** are the same cube sliced by the real Orca on 2026-10-25 with print-shop's own `profiles/`, for a 0.4 and a 0.8 nozzle, in PLA and PETG, on the textured PEI plate (`tests/test_preset_slices.py`, mqucifer/print-shop#6). Only Orca's comments and the temperature commands are kept, which is all those tests read. `PRINT_SHOP_RECORD=1 uv run pytest -m slicer tests/test_preset_slices.py` rewrites them. Note that `cube.gcode` and `cube_pei.gcode` above came from Orca's system files without their parents, so every key those files don't set is Orca's built-in default (their `filament_vendor` is "(Undefined)", and the PEI bed is 45 °C where Elegoo's PLA says 60).
- **`profiles/`** carries only what the pipeline reads from a profile without Orca: the build volume (257 mm, what the real profile resolves to) and the process profile's printer list.
- **`sdcp/frames.json`** is **synthetic**: SDCP payloads built from pycentauri's models, not recorded from the printer. No test contacts the printer. The first real frames are recorded at the Sponsor's first deliberate print (mqucifer/print-shop#3) and replace these.
